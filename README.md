# Smart Energy Occupancy Prediction (TinyML Project)

## Project Overview

This project predicts room occupancy using sensor data such as motion detection, light levels, and time of day. The goal is to optimize energy usage in smart buildings by automatically determining whether a space is occupied.

The model was built using IBM watsonx AutoAI.

## Problem Statement

Buildings waste energy when lights and systems remain active in empty rooms. This project uses machine learning to detect occupancy and help automate energy-saving decisions.

## Input Features

* Motion Sensor (0 = No motion, 1 = Motion detected)
* Light Level (0–100 brightness scale)
* Time of Day (0–23 hours)

## Output

* Occupied (1)
* Not Occupied (0)

## Model Used

Decision Tree Classifier generated by IBM watsonx AutoAI.
